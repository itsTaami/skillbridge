----------------------------------------------------------------
  SCENE 8 — ARCHITECTURE  (~ 1.5 minutes)
----------------------------------------------------------------

[Stay on any page. You're just talking now — no clicking needed.]

SAY:
  "Quick architecture overview for the technical side."

SAY:
  "The whole app is Next.js 13 with the Pages Router.
   Pages are server-side rendered — getServerSideProps runs
   on the server, fetches data from Supabase before the HTML
   is sent to the browser."

SAY:
  "The API routes are serverless functions deployed on Vercel.
   They use a service role key to talk to Supabase — that key
   never touches the browser."

SAY:
  "Auth is Supabase Auth. When you sign up, a PostgreSQL
   trigger fires automatically and creates your profile row.
   Row Level Security is enabled — users can only read and
   write their own data."

SAY:
  "The AI Match feature calls Groq from a serverless route.
   The API key stays server-side. The model returns structured
   JSON — recommendation, traits, keywords — and then we use
   those keywords to query the real database."


----------------------------------------------------------------
  SCENE 9 — CLAUDE CODE / AI COLLABORATION  (~ 1.5 minutes)
----------------------------------------------------------------

SAY:
  "For the AI collaboration part of the rubric — I used
   Claude Code throughout this project."

SAY:
  "First, there's a custom slash command called /skill-advisor.
   It's a project-specific skill — when I run it in Claude Code,
   it acts as a domain expert that understands SkillBridge:
   tutoring, freelancing, the database schema. I used it to
   generate listings, blog content, and seed data."

SAY:
  "Second, there's a /generate-profiles command that uses the
   Ralph Wiggum autonomous loop technique — Claude runs in a
   loop, autonomously generating realistic tutor and service
   profiles and POSTing them directly to the live API, without
   any human input between iterations."

SAY:
  "And the third AI feature is the one you already saw —
   AI Match built into the product itself. That's Groq's
   Llama 3.3 70B returning structured JSON and searching
   the real database."

SAY:
